# Обозреваем TS: от данных к React

[Открыть лекцию на GitHub Pages](https://ngg-dev.github.io/ts-lecture/)

Четвёртая лекция курса: **55 слайдов, 70 минут рассказа + 5 минут на вопросы**. Сохраняем знакомый книжный магазин, задачи с ценой, props, корзиной и состоянием. Цель: применить базовые типы в небольшом React-проекте и понимать сообщения компилятора.

Оформление – инженерный чертёж: синяя сетка, контурные схемы и жёлтые акценты. Намеренные ошибки показываются рядом с рабочим кодом или следующим слайдом: красная строка, подчёркивание и настоящая диагностика TypeScript. Все шаги объяснения переключаются основными стрелками.

## Маршрут

1. **Задача и запуск – 13 минут.** Работающий магазин, цена строкой, назначение TS, проверка и компиляция, создание shop.ts и tsconfig.json.
2. **Базовые типы – 16 минут.** Вывод типов, функции, Book, optional, null, переиспользование type, any/unknown и простая проверка typeof.
3. **Контракты – 5 минут.** interface, расширение через extends и &, практическая разница type/interface.
4. **Простые union – 4 минуты.** Статусы и значение string | number, уточнение через typeof.
5. **Утилиты – 6 минут.** Pick для карточки, Omit для новой книги, Record для корзины.
6. **Дженерики – 2 минуты.** Параметр типа и угловые скобки на коротком примере `useState<number>`.
7. **TypeScript в React – 24 минуты.** Настройка .tsx, props и callbacks, вывод и параметры useState, события input и формы, ReactNode, ComponentProps и Promise для результата API-запроса.

Готовые типы React приходят из @types/react; DOM-типы предоставляет TypeScript. У сторонних библиотек сначала изучаем их собственные объявления и экспортируемые типы. Параметры типов рассматриваем через useState<Book[]> и Promise<Book[]>.

useRef, useEffect, собственный хук, сложные generic-функции, keyof/T[K], never, подробная структурная совместимость, discriminated union и дополнительные утилиты сохранены в `docs/extra-topics.md`. Они не входят в основной показ.

## Запуск

Node.js 22+:

```sh
npm ci
npm run check
npm run build
npm run dev
```

Откройте http://127.0.0.1:4189/dist/. Сервер не пересобирает исходники автоматически: после правок выполните `npm run build`. `npm run preview` показывает dist на том же порту; сначала остановите dev.

`dist/` готова для статического хостинга с относительными путями и hash-адресами. Для демо не нужны внешние API. Показ работает автономно после сборки.

## Управление и демонстрации

- Стрелки, Page Up/Down, Home/End – общий маршрут; O – оглавление, F – полный экран, Escape – закрыть оглавление.
- Ввод и кнопки внутри демонстраций не переключают слайды.
- Строку кода можно выделить нажатием. Кнопок копирования в режиме показа нет.
- `#compiler-output`: исходный TS и настоящий результат компиляции в JavaScript. Интерактивный компилятор удалён из показа.
- `#react-generics`: краткое объяснение параметра типа перед слайдами о useState.

## Материалы и проверки

- `src/content.js` – основной маршрут, тайминг и заметки; `src/examples.js` – 52 TS-примеров, включая дополнительные.
- `src/react-examples.js` – 18 React-примеров, проверяемых с реальными типами React; `src/example-pairs.js` – пары рабочего и ошибочного кода.
- `src/main.jsx`, `src/BlueprintDrawing.jsx`, `styles.css` – оболочка и оформление.
- `examples/BookCatalog.tsx`, `examples/PriceEditor.tsx` – цельное работающее React-демо; `examples/standalone/` – запуск без React.
- `docs/speaker-guide.md` – отдельные заметки преподавателя; `docs/practice.md` – практика; `docs/extra-topics.md` – дополнение; `docs/sources.md` – первичные источники.
- `docs/prior-knowledge.md` – анализ предыдущих лекций, выполненный отдельными субагентами.

Проверка контролирует структуру и 70 минут основного рассказа, компилирует обычные и React-примеры, сверяет ожидаемые ошибки, проверяет номера строк диагностики, TSX-проект и реальный запуск standalone JS. Сборка генерирует диагностику для слайдов и отдельные материалы преподавателя.

## Публикация
